# Local, layout-aware MinerU runtime for uploaded PDF projects.
# Install only on the VM where extraction is required. MinerU downloads its
# pipeline models to its own cache on first real parse; do not package model
# caches in the Retreiver ZIP.
#
# The legacy `magic-pdf` package is intentionally not used: version 1.3.12
# has a known model-weight mismatch (PP-OCRv3 vs PP-OCRv5). MinerU 3.x is the
# maintained CLI and emits structured content lists, tables, image crops, and
# layout artifacts used by DocumentParserService.

PyYAML>=6.0
PyPDF2>=3.0.1
